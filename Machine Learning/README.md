# Análise de Prescrição de Lentes de Contato

Este projeto contém uma análise simplificada de um conjunto de dados de prescrição de lentes de contato, baseado em características dos pacientes.

## Dataset

O conjunto de dados inclui informações sobre 23 pacientes com as seguintes características:
- ID: Identificação do paciente
- Idade: Categorizada em jovem, pré-presbiópico e presbiópico
- Diagnóstico: míope ou hipermetrope
- Astigmatismo: sim ou não
- Produção Lacrimal: normal ou reduzida
- Lente Prescrita: nenhuma, gelatinosa ou rígida

## Requisitos

Para executar o código, instale as dependências:

```bash
pip install -r requirements.txt
```

## Executando a Análise

Para executar a análise básica dos dados:

```bash
python contact_lens_analysis.py
```
